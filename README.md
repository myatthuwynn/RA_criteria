# ACR/EULAR 2010 RA Criteria Calculator

**Objective scoring system for Rheumatoid Arthritis diagnosis - Score ≥6 = Definite RA**

## 🎯 Features
- ✅ Real-time score calculation
- ✅ Automated diagnosis interpretation
- ✅ Management recommendations
- ✅ Print-friendly reports
- ✅ Mobile responsive
- ✅ Works offline (no dependencies)

## 📊 Scoring Criteria
- **Joint Involvement:** 0-5 points
- **Serology (RF/Anti-CCP):** 0-3 points
- **Acute Phase Reactants (ESR/CRP):** 0-1 point
- **Symptom Duration:** 0-1 point

**TOTAL: 0-10 points**

## 🚀 Usage
1. Open `index.html` in any web browser
2. Fill in patient information
3. Score auto-calculates in real-time
4. View automated diagnosis & management plan
5. Print report when ready

## 🔬 Clinical Details
- **Developed by:** ACR/EULAR 2010
- **Target:** Early RA diagnosis and management
- **Applicable at:** First visit (if ≥6 weeks symptoms)
- **Score ≥6:** Start disease-modifying therapy (MTX)
